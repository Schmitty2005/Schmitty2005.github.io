procedure PinkNoise(var aPCM: TNoise; aLengthms: UInt64; aAmplitude: UInt16 = 27000; aSampleRate: UInt32 = 44100);

Generates pink noise (1/f noise) with specified parameters

Parameters
aPCM
- Output array that will contain the generated samples
aLengthms
- Duration of the noise in milliseconds
aAmplitude
- Peak amplitude (default: 27000, max safe: 32767)
aSampleRate
- Sample rate in Hz (default: 44100)
