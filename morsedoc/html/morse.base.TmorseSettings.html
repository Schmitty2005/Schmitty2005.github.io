Set the level of the output. A good start would be 70% of max Integer value

Set Farnsworth Spacing WPM, if enabled, otherwise, no affect

Set the noise type to off, white, or pink

Set the noise level. It should be the inverse of the morseLevel, 30 % of max Integer value, for example
