Functions and Procedures

function StringReplace(const S, OldPattern, NewPattern: string; Flags: TReplaceFlags): string;

Same semantics as SysUtils.StringReplace: - Without rfReplaceAll, only the first match is replaced. - With rfIgnoreCase, matching is case-insensitive (ASCII only here). - An empty OldPattern returns S unchanged. - Replaced text is never rescanned (no recursive replacement).
