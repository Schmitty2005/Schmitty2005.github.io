Description

The base unit for the Morse-lib. These are what are needed to configure the morse code generator. A default settings is provided called DefaultMorseSettings. The settings are as follows : 

WPM : 18
Farnsworth : Disabled
Noise : Disabled
Tone Hz  : 800 Hz
Volume : (TBA)
